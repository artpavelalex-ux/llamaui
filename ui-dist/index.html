Настройки

Модель чата выбирается списком внизу слева. Все блоки ниже — сворачивающиеся (по умолчанию свёрнуты).
Общие (General)
Как в оригинале: либо первая непустая строка, либо модель сама придумывает название.
Текст длиннее этого значения при вставке превращается в прикреплённый файл.
Сэмплирование (Sampling & Penalties)
Случайность текста: выше — креативнее, ниже — точнее.
-1 — без ограничения.
-1 — выключено. Берёт K самых вероятных токенов.
-1 — случайно. Фиксированный = воспроизводимость.
Штрафы и анти-повторы (Penalties)
1 — выключено. Штраф за повтор токенов.
Сколько последних токенов штрафуется. -1 — весь контекст.
0 — выключено. Штраф за само присутствие токена.
0 — выключено. Штраф растёт с частотой повтора.

DRY (повторы последовательностей)

0 — выключено.
Особые режимы сэмплинга
0 — выключено. Температура адаптируется под уверенность модели.
0 — выключено. Вырезает очевидные токены (творческий режим).
0 — выключено, 1/2 — адаптивная перплексия.
Порядок сэмплеров (Samplers)
Сэмплеры применяются по порядку сверху вниз (как в оригинальном интерфейсе). Снимите галочку, чтобы выключить сэмплер, стрелками меняйте порядок.
Сэмплеры считаются на GPU — быстрее на длинных генерациях.
Размышления (Reasoning)
Выключено — reasoning-модель отвечает сразу, без блока размышлений.
reasoning_format=none — размышления придут внутри текста ответа.
Не отправлять блоки размышлений предыдущих ответов обратно модели.
Вид (Display)
Токены в промпте/ответе и скорость генерации.
Без ограничений высоты и прокрутки внутри блока.
Вложения (Attachments)
Сканировать PDF картинками, а не текстом (для vision-моделей).
0 — без ограничения. Большие картинки уменьшаются перед отправкой.
Производительность (Performance)
После каждого ответа диалог заранее кодируется на сервере — следующий вопрос обрабатывается быстрее.
Для разработчика (Developer)
JSON мерджится в запрос к серверу — для параметров, которых нет в интерфейсе.
CSS внедряется в страницу при запуске (Custom CSS из оригинала).
Переключатель Markdown/чистый текст на каждом ответе.
Системная подсказка и память
Пусто — шаблон модели по умолчанию.
0 — помнить весь диалог.
